# Contributing

## General

This repository is a part of the *novelibre* software project. 
Please be sure to follow the 
[central contribution guidelines](https://github.com/peter88213/novelibre?tab=contributing-ov-file).

```
.
├── novelibre/
│   ├── src/
│   │   └── nvlib/
│   └── tools/ 
│       ├── inliner.py
│       └── package_builder.py
└── novx_xtg/
    ├── src/
    │   └── nvxtglib/
    └── tools/ 
        └── build.xml
```
